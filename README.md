# IAMTECHNI: Motion Studio

BUILD IAMTECHNI AS AN ART-DIRECTED DIGITAL EXPERIENCE — NOT A CORPORATE TEMPLATE

You are not being asked to make a normal technology-company website.

You are a world-class creative director + senior UI/UX designer + creative frontend engineer.

Build a website for iamtechni using the attached logo as the core visual inspiration.

The result must feel like a website from a future-facing technology studio, not a traditional IT company.

THE MOST IMPORTANT RULE

DO NOT BUILD THIS:

Navbar → Hero → Stats → About → Service Cards → Projects → Testimonials → CTA → Footer.

That structure is predictable and forbidden.

Do not make a Bootstrap-style website.

Do not make a SaaS landing page.

Do not make a generic "modern tech" website.

Do not fill the page with cards.

Do not use stock-photo corporate people.

Do not make every section centered.

Do not make every section look like a rectangular container.

I want an experience that makes someone stop scrolling and think:

"What the hell is this website?"

Then:

"This is incredibly well designed."

01 — CREATIVE CONCEPT

Create a visual language called:

"TECHNOLOGY IN MOTION"

The iamtechni logo contains a very strong visual idea:

diagonal bars + movement + progression + a floating gold element.

Do NOT simply put the logo in the navbar.

Extract its geometry and make it the design language of the entire website.

The diagonal shapes should reappear throughout the experience as:

navigation indicators

section transitions

image masks

animated lines

progress indicators

background architecture

cursor interactions

typography clipping

scrolling transitions

decorative objects

page transitions

The website should feel like the logo has become an interactive world.

02 — VISUAL DIRECTION

Think:

Apple product launch + high-end digital agency + experimental editorial design + futuristic interface + architectural visualization

But do NOT copy any existing website.

The design should be:

experimental

sophisticated

minimal

cinematic

asymmetric

intelligent

highly interactive

premium

memorable

Use huge typography.

Use extreme whitespace.

Use unexpected positioning.

Use depth.

Use scale.

Use motion.

Use overlapping elements.

Use negative space.

Use controlled visual chaos.

The design should feel designed, not assembled from components.

03 — COLOR SYSTEM

Use the uploaded iamtechni logo as the source of truth.

Extract and refine its colors.

Primary visual colors:

--navy: #193B8F;

The gold dot in the logo should feel like a valuable visual object.

04 — NO NORMAL NAVBAR

The navigation should be unconventional.

Instead of a standard horizontal navbar, create a floating command/navigation system.

Desktop idea:

The logo sits in the upper-left.

Navigation appears as a small floating vertical/horizontal interface rather than a traditional menu.

For example:

        iamtechni

        01
        02
        03
        04
        05


Or an elegant floating navigation rail.

As the user scrolls, the navigation transforms.

The current section becomes represented by the animated diagonal logo geometry.

Navigation should feel like an instrument panel, not a menu.

On hover, navigation labels reveal themselves.

On mobile, transform this into a beautiful full-screen interactive navigation.

Do NOT make a conventional hero with:

left text + right image.

Instead create an immersive full-screen composition.

The first screen should contain:

WHAT'S NEXT.

or:

IN MOTION.

The typography should be enormous and partially cropped by the viewport.

The logo's diagonal bars should travel through the typography.

06 — HERO INTERACTION

The hero must react to the user.

Mouse movement should subtly affect:

depth

diagonal shapes

glow

typography

floating objects

The gold dot should respond subtly to cursor movement.

The diagonal elements should have different movement speeds.

Create a subtle 3D/parallax spatial effect without requiring WebGL unless you can implement it reliably.

If using WebGL/canvas, keep performance excellent.

The hero should feel alive even when the user isn't interacting.

07 — SCROLL EXPERIENCE

Do NOT simply scroll through static sections.

Create a story.

As the user scrolls:

PHASE 01

The huge hero typography begins breaking apart.

PHASE 02

The diagonal logo elements expand across the screen.

PHASE 03

Those diagonal elements transform into a visual representation of the company's capabilities.

PHASE 04

Content emerges from the movement.

PHASE 05

The page transitions into the next visual world.

The user should feel that scrolling is controlling the interface.

Use:

sticky sections

horizontal movement

pinned elements

scale transitions

clip-path

transforms

opacity

blur

parallax

typography transformations

But keep it elegant.

08 — COMPANY INTRODUCTION

Instead of an "About Us" card:

Create a huge editorial statement.

For example:

WE DON'T JUST BUILD SOFTWARE.

WE BUILD THE SYSTEMS
THAT MOVE BUSINESSES FORWARD.

Make this occupy a large portion of the viewport.

Certain words should animate independently.

When scrolling, individual words can move at different speeds.

Add a tiny supporting paragraph somewhere unexpected.

Do not use a traditional two-column About section.

HTML5 + CSS3 + Vanilla JavaScript

Implement:

performance optimization
